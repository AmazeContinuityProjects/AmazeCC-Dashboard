title: "Glossary"
description: "Plain-language definitions of the web, React, API, and admin terms used throughout the AmazeCC Dashboard handbook."
---

| Term | Meaning in this handbook |
|---|---|
| API | A set of URLs and rules another program can use to request data or actions |
| App Router | Next.js's file-based routing system used under `src/app/` |
| Browser | The program on a user's device that displays the site and runs its client code |
| Build | The process that converts source code and assets into deployable files |
| Component | A reusable React function that returns part of the interface |
| CORS | Browser security rules that control requests between different website origins |
| Environment variable | A named configuration value supplied outside ordinary source code |
| HTTP | The request-and-response protocol used by browser and server |
| JSON | A text format for objects, arrays, strings, numbers, booleans, and null |
| Local storage | Browser key/value storage that survives reloads for one website origin |
| Prop | A value a parent React component passes to a child |
| React | The JavaScript library this project uses to build interactive interfaces |
| Server | A program running elsewhere that responds to client requests |
| State | A component's remembered value; changing it causes React to render again |
| Static export | A build mode that outputs files a static website host can serve |
| TypeScript | JavaScript with optional types that help developers catch mistakes |
| VAPID | Keys used to identify an application server when it subscribes a browser to web push |
